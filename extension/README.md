# ClearLead Application Copilot

1. Start ClearLead at `http://127.0.0.1:4173`.
2. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select this `extension/` folder.
3. In ClearLead, save the Application Identity profile and choose **Create pairing token**.
4. Paste the token into the extension.
5. Search and verify a role, then choose **Prepare autofill** and open the application.
6. Use **Fill safe fields** in the extension.
7. Review highlighted fields, upload the selected resume, and choose **Check application status**.
8. When the run is ready for final approval, review once and press Submit yourself. Check status again on the confirmation page to record completion evidence.

Green outlines were safely filled. Amber fields need review. Red fields are sensitive/legal and remain untouched. Blue fields, including resume file uploads, require manual action. The extension never clicks Submit.
